使用指南

从配置到使用，手把手教你快速上手智答AI

快速开始

1

获取 API Key

智答AI 需要调用大模型 API 来解答题目。推荐注册智谱 AI（永久免费）：

  1. 打开 智谱开放平台
  2. 用手机号注册账号
  3. 进入「API Keys」页面，点击「创建 API Key」
  4. 复制以 sk- 开头的 Key
💡 提示

智谱 GLM-4-Flash 模型永久免费，新用户赠送 1000 万 tokens，足够日常使用。

2

配置 API Key

进入答题页面，点击右下角 ⚙️ 设置按钮：

  1. 选择「智谱 AI · GLM-4-Flash」
  2. 粘贴刚才复制的 API Key
  3. 点击「测试连接」，看到 ✅ 即可开始使用
⚠️ 注意

API Key 保存在浏览器本地，换设备或清除浏览器数据后需要重新配置。

使用流程

1

输入题目

支持四种方式输入题目：

方式操作适用场景
📷 拍照上传点击 📎 按钮，选择拍照或相册纸质作业、试卷
📄 PDF 文件点击 📎 按钮，选择 PDF 文件电子试卷、习题集
🔗 粘贴网址点击 🔗 按钮，粘贴题目网页链接在线题库、网页题目
⌨️ 直接输入在输入框打字描述题目简单题目、补充说明
2

选择模式

页面顶部有两个模式按钮：

  • 仅答案：快速给出答案，适合检查作业
  • 答案+过程：详细步骤讲解，适合学习理解
3

发送并查看解答

点击发送按钮或按回车，AI 会自动分析题目并给出解答。解答过程会实时流式显示，无需等待。

4

追问深化

每道解答下方有三个追问按钮：

  • 详细解释：用更简单的方式重新讲解
  • 简洁回答：只保留核心答案
  • 类似题目：出一道同类练习题巩固

也可以直接在输入框打字追问任何问题。

常见问题

为什么需要 API Key？
智答AI 使用大语言模型来解答题目，需要调用模型厂商的 API。API Key 是你与模型服务通信的凭证。我们推荐智谱 GLM-4-Flash（永久免费），你也可以使用自己的 OpenAI 或 Gemini Key。
API Key 安全吗？
安全。API Key 只保存在你的浏览器本地（localStorage），不会上传到任何服务器。题目图片的 OCR 识别也在浏览器本地完成，不会上传原图到第三方。
支持哪些类型的题目？
理论上支持所有文字类题目：数学、物理、化学、生物、英语、语文、历史、地理等。对于需要复杂图形分析的纯几何题，识别效果取决于图片清晰度。
手机上能用吗？
完全可以。智答AI 是响应式网页，手机浏览器打开就能用。推荐使用手机自带浏览器或 Chrome/Safari，拍照上传功能在手机上体验最佳。
为什么 OCR 识别需要时间？
首次使用 OCR 时，浏览器需要从 CDN 下载 Tesseract.js 引擎和中文语言包（约 10MB），这个过程需要 10-30 秒，取决于网络速度。下载完成后会缓存到本地，后续使用会快很多。
答案不准确怎么办？
大模型偶尔会出错，特别是复杂计算题。建议：1）使用「详细过程」模式检查步骤；2）对不确定的答案进行追问验证；3）关键考试请以教材和老师讲解为准，AI 仅作为辅助工具。

隐私说明

我们非常重视你的隐私：

  • 图片不上传：题目图片在浏览器本地完成 OCR 识别，原图不会离开你的设备
  • Key 存本地：API Key 保存在浏览器 localStorage，不存储在服务器
  • 纯静态页面：没有后端服务器，不收集任何用户数据
  • 无痕使用：可以开启浏览器的隐私/无痕模式使用，关闭后不留痕迹
